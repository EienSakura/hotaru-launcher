# Hotaru 局域网插件开发版实测

两台电脑都使用同一份预装插件的局域网开发预览包。退出旧 HotaruDev，从新 ZIP 解压后运行 `HotaruDev.exe`，用 **Ctrl+Alt+H** 打开「设置 → 插件」。开发版与正式版的数据、登录项和默认热键独立。

1. **安装**：解压运行后，在「全部」「基础服务」「功能插件」标签检查两列卡片和名称旁的「Hotaru直属」徽标，确认三个插件均已加载且默认关闭。「全部」中两个分组默认展开，可各自折叠；切到单独分类仍能看到全部卡片，切回「全部」保留折叠状态。单独验证导入时使用一个未运行的测试副本，将副本中的 `native-plugins-dev` 移到备份位置再启动，先导入 `hotaru-plugin-lan-core-<版本>-x64.zip`，再导入两个功能包，全部导入后重启一次。先导入功能包应提示缺少前置，重复导入不会覆盖。
2. **配对**：两台电脑连接同一可信的 Windows 专用网络，分别启用「局域网连接」。A 点「生成邀请码」；B 打开「发现邀请」，核对列表中的电脑名称和 IPv4，输入五位码并发起配对；A 核对 B 的设备名并确认。只有配对完成、常规连接建立后，两台才显示在线。即使未开启剪贴板和文件分享也能配对。
3. **发现与失败**：只有一个邀请时应自动选中，有多个时按名称和地址选择。结束邀请后不应继续发现其名称；自动发现失败时在 B 手填 A 的 IPv4。测试错码、过期、拒绝和取消。五次失败后须重新生成码。两端只启用局域网连接时，配对后等待至少 30 秒，在线状态不应来回跳动；重启后应自动重连；撤销一台设备后，该设备需重新配对。切换成公用网络应在几秒内断开。
4. **剪贴板**：启用后复制文本和小截图，在另一端检查当前剪贴板和「局域网」来源。完整输入 `clip`，首屏最多本机与局域网各一条、另加最近五条历史；新配置的记录开关默认打开，在同步与快捷词右边的「本机记录」栏。关闭记录后先在本机复制，再从另一台机器发送不同内容，确认两条仍同时显示且没有写入历史。来源和时间显示在每项内容下方，底部始终能打开完整记录，包括空记录；每批 30 条。用「本机」或「局域网」筛选，用筛选框左侧的「返回」或 Esc 回到首屏，Enter 恢复，Ctrl+Enter 粘贴。确认恢复不会重新同步，关闭记录不再保存新内容，关闭插件后唤醒词回归普通搜索。自定义词仍可修改或留空关闭。
5. **文件**：启用文件分享，在启动器输入 `@` 或 `@设备名前缀`，选中设备进入发送面板。左栏发送，右栏接收；在左栏试选文件、文件夹和拖入。对方点击托盘通知直达接收面板；确认前目标目录无新增文件。点「接收」使用默认目录，点「另存到」临时换目录；默认目录不可用时仍可另选。成功的文件存入「Hotaru 接收」子目录；同名传输保留多份。
6. **独立启停**：关闭文件分享后，`@` 回到普通搜索，剪贴板仍可用。关闭前置时两项都暂停，正在进行的传输停止；再次开启前置，原有配对和功能开关恢复。另测拒绝接收、取消、传输时断网及重试。

旧共用安全码版只迁移设备名和剪贴板快捷词，两端需更新后重新配对。旧默认词 `jtb` 改为 `clip`；保留其他自定义词及留空状态。本机旧历史继续可用。不要发送邀请码、文件内容或设置文件。

7. **退出**：打开设置后从托盘选「退出」，确认弹窗只问「是否退出 Hotaru？」并提供「确认」「取消」；取消后保持运行，再确认退出。传输中退出会断开并清理未完成文件。打开文件选择器时，先关闭选择器再处理退出确认。检查「连接诊断」在明暗两种设置主题都能看清和展开。

## 连接诊断

在「局域网连接 → 连接诊断」查看 TCP、UDP、组播和 DNS-SD 状态，或探测对端 IPv4。专用网络的 TCP/UDP 使用固定端口 `45456`，发现依次使用 DNS-SD、UDP 组播/定向广播、限速 TCP 注册和已配对缓存地址。发现只表示对端可尝试连接。只有正常会话认证后才允许共享。若有防火墙提示，只允许专用网络；应用不会修改防火墙。

诊断日志位于开发数据目录的 `lan-connection` 子目录。单份上限 128 KiB，最多保留当前和上一份。日志包含连接阶段、地址、端口和接口索引，不记录设备名、邀请码、凭据、剪贴板内容或文件名。如需反馈，只提供 `lan-diagnostics.log`、必要时的 `lan-diagnostics.previous.log` 和复现步骤。

正式版的官方仓库隐藏 LAN 预览包，只显示符合宿主要求的已签名正式包。两版均可手动导入兼容的本地 ZIP；正式版不预装 LAN 插件。
