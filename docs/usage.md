# Hotaru 使用指南

[返回 README](../README.md) · [功能变更记录](changes.md) · [开发说明](development.md)

## 呼出与设置

默认按 `Alt+Space` 呼出或收起启动器，也可以点击托盘图标。热键冲突时程序会使用备选热键，实际绑定可在设置和日志中查看。每次呼出会清空上次查询，面板页码按设置恢复。

点击齿轮进入配置页。完整面板的齿轮位于底栏右侧；收起常驻网格时位于搜索条右侧。设置窗口会还原并居中到启动器所在屏幕，关闭后可以再次打开。

“呼出时显示常驻网格”控制的是整个固定面板：

| 开关状态 | 呼出后显示 |
| --- | --- |
| 开启，默认 | 搜索框、固定网格、页码和底栏。 |
| 关闭 | 仅搜索条；输入后按搜索结果展开，清空后收起。 |

关闭不会删除固定项，启用的固定项仍然参与搜索。对于带装饰的皮肤，顶部角色保留；底部角色在结果区展开时恢复播放，清空后隐藏并暂停。空搜索状态不保留一条多余的面板底框。

## 添加和管理固定项

首次启动固定面板为空。在空白格右键，选择“添加软件或脚本…”或“添加文件夹…”，新项目会放进所点空格。设置的“外观 → 固定软件”也提供添加、启用、禁用、属性和移除入口。

| 支持的目标 | 行为 |
| --- | --- |
| `.exe` | 启动独立进程，可配置参数和工作目录。 |
| `.lnk` | 保留快捷方式自身的目标、参数和工作目录。 |
| `.bat`、`.cmd` | 通过 Windows 命令解释器启动。 |
| 文件夹 | 在资源管理器中打开。 |

普通文档和图片不提供固定入口。目标失效时仍保留图标配置，并提供重新定位入口。

右键固定项可以运行、打开所在位置、重命名、编辑属性或移除。可以提权的程序或脚本提供“以管理员身份运行”，文件夹不提供该操作。属性可编辑显示名、目标、参数、工作目录、图标和格位。

“重命名…”或选中后按 `F2` 只修改面板显示名。名称去掉首尾空白后不能为空，可以重名；源文件、快捷方式和磁盘目录的名字及内容均不改变。“移除”也只移除固定配置，不删除源文件。

禁用的固定项不显示，但仍保留并占用原位置；需要释放格位时应移动或移除它。

## 自由格位与页面

默认每页 **4 行 × 8 列**。设置“每页网格”可以调整为 2–6 行、4–8 列，“打开面板时”可以选择每次回首页或记住上次所在页。

图标可以拖到任意空格。拖动时显示虚线网格和目标反馈，松手吸附到格位，原位置留空；其他图标不会挤动或自动补位。未进入分组合并预览时，已占用格不接受放置。

底栏的上一页、下一页和页码用于翻页，滚轮及 `PageUp` / `PageDown` 同样可用。加号可增加空白页，新增空页会保存，重启后仍保留。主面板和分组面板均无滚动条；搜索列表的长结果允许纵向滚动。

跨页拖动时，将图标停留在左右边缘约 650ms 即可翻页，持续停留可以继续翻页。在最后一页继续向右拖动会预览新页，成功放下才保存。按 `Esc`、拖到区域外松手、失焦或保存失败时，恢复起始位置和页面。

右键页码或主面板空白处选择“删除当前页”。至少保留一页：

- 空页直接删除。
- 非空页可以迁移图标到其他现有页面的空格，或仅移除此页配置。
- 迁移容量不足时默认保留当前页，也可再次明确选择移除。
- 后续页码前移，各页内部格位不自动整理；分组连同子项一起迁移。

减少列数前，应先移动右侧超出新范围的项目，禁用项目和分组同样受保护。调整行数会改变分页划分，但保留原有行列位置。

## 图标分组

将一个图标拖到另一个图标中心并停留约 500ms，出现合并预览后松手，会在目标格创建“新建文件夹”。将图标拖到已有分组上完成同样停留，可以加入分组。

分组封面展示前四个启用子项的缩略图。点击分组打开二级弹层，每页固定 3×3；子项支持运行、重命名、右键操作、自由格位和跨页拖动。点击弹层外或按 `Esc` 关闭。

子项拖到弹层外停留约 350ms，会返回主面板继续拖放，也可以再跨页放置；取消时恢复原分组位置。

右键分组可打开、重命名或解散。解散仅使用现有页面空位，空间不足时保留分组并提示。分组剩一个子项时保留，最后一个子项移出或被移除后自动移除空分组。

只支持一层分组，不能把分组放入另一个分组。这里的“文件夹”只是图标分组，实际磁盘文件夹仍作为普通启动项处理。

## 搜索与快捷操作

输入名称、拼音或路径进行搜索。固定项也匹配其显示名、分类和路径，分组内的启用项目同样参与搜索；搜索不会改变首页布局。

应用、固定项和文件结果右侧预留操作区，只在悬停或键盘选中当前行时显示按钮：

| 操作 | 说明 |
| --- | --- |
| 打开所在位置 | 在资源管理器中定位目标；应用优先定位真实程序，无法解析时回退快捷方式。 |
| 固定到面板 | 仅支持的程序、脚本和文件夹可用；放入所有页面从左上开始的首个空格，保留当前查询。 |
| 已固定 | 同目标、参数和工作目录已存在时不重复添加，包括禁用项和分组内项目。 |

`Alt+O` 定位当前搜索结果，`Alt+P` 固定当前支持的结果。点击右侧按钮不会同时启动该行；右键菜单也提供对应操作。

搜索列表使用回车或双击打开结果。主面板固定项单击运行，拖动结束不会误触启动。

## 外观与工具插件

在“配置 → 外观”选择内置黑色、灰色或白色主题，也可导入 ZIP 主题包。切换立即生效，重启后记住选择；用户主题可删除，删除当前用户主题后回到黑色，内置主题不可删除。

皮肤可包含外框、静态装饰和 GIF。主题只影响启动器；设置和标准提示框使用独立的基础日间或夜间配色。插件自行绘制的图片和控件不保证跟随启动器皮肤。

蓝色机械皮肤名为“2233娘主题包”，通过独立 ZIP 导入，不随源码或内置主题分发。主题采用本仓库 Release 独立附件的发布方式；当前该包尚未公开发布，确认素材再分发授权后再提供下载。制作与安装规则见[主题包设计规范](theme-package.md)。

DLL 工具插件与 ZIP 皮肤是两种独立扩展。默认构建不捆绑工具插件，首次进入 Hotaru 时关闭继承的插件自动更新，之后可由用户主动开启。已有插件文件保留，不会自动放入固定面板。图片排版、随机数、JSON、Base64 等功能需安装对应 DLL 后使用。

现有工具插件均来自上游 ltool，插件商店仍使用上游渠道；Hotaru 暂未进行兼容性测试，使用前需要自行适配和验证。主程序默认不附带插件；分发插件需要额外构建、验证和打包。

“关于”页展示 Hotaru 版本与本机信息，提供 [本项目仓库](https://github.com/EienSakura/Hotaru) 和发布页入口，暂不启用应用内更新。Hotaru 从 `1.0.0` 开始独立计版。

## 配置与备份

数据目录的选择顺序为：`LTOOL_DATA_DIR` 环境变量、可写的程序旁 `data/`、`%APPDATA%/ltool` 回退目录。配置页可打开实际数据目录。

```text
<数据目录>/
├─ config.ini             通用设置、呼出网格开关、插件更新选项
├─ log.txt                运行与错误日志
├─ hotaru/
│  ├─ config.json         固定项、分组、页面、格位和主题选择
│  └─ themes/             已安装的用户主题
├─ icons/                 可重建的图标缓存
└─ ...                    上游搜索索引、网站与其他功能数据
```

“导出配置”保存 Hotaru 的布局和主题选择，包含各固定项参数、分组与页码；“导入配置”按完整布局校验后替换配置。它不打包软件本体、主题资源或 `config.ini` 中的通用设置。迁移到其他机器时，目标路径可能需要重新定位，用户主题需要另行安装。

完整备份应在退出程序后复制整个数据目录；需要保留已安装的 DLL 工具时，还应复制程序旁的 `ltool-plugins/`。复制配置不会复制被启动的软件或实际文件夹。

布局保存采用原子写入。旧布局迁移前保留备份，损坏配置会保留带 `.corrupt-` 的副本并恢复默认值。遇到设置无法显示、启动失败或主题导入错误时，先查看界面提示和数据目录的 `log.txt`。
