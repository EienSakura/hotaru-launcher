# Hotaru 功能变更记录

[返回 README](../README.md) · [使用指南](usage.md) · [开发说明](development.md)

## 1.0.1

发布日期：2026-10-31。本节记录从 Hotaru 1.0.0 到 1.0.1 的功能与体验更新。

### 快捷键与启动稳定性

- 快捷键录入改为独立等待输入弹窗，捕获期间暂停现有全局热键，实时显示 `Ctrl`、`Ctrl+Alt`、`Ctrl+Alt+K` 等组合，支持 `Alt+Space`、`Ctrl+K`、`Ctrl+Alt+K` 和双击 Ctrl。
- 保存前后统一执行系统冲突检测；注册失败时恢复原组合，不保存不可用快捷键。
- 退出时显式释放全局热键、双击 Ctrl 钩子和单实例管道；F1/F2 只在对应插件启用并声明动作时注册。

### 固定面板与设置页

- 分离“添加磁盘文件夹”和“新建面板文件夹”：前者保存真实目录并打开资源管理器，后者只创建面板内分组，不写入磁盘路径。
- 主面板右键菜单增加添加程序、添加磁盘文件夹和新建面板文件夹；分组面板禁止继续创建子分组。
- 固定项导入与快捷搜索导入统一为可拖入或点击选择的二级弹窗，拖入过程中提供状态动画和结果反馈。
- 重命名使用统一弹窗，取消或 Esc 不会留下新分组；空名称会即时提示并禁止确认。
- 设置页统一卡片、间距、矢量图标和滚动布局；固定软件列表显示图标、状态、路径和格位信息。
- 主面板网格限制统一为 4–8 列、2–6 行，分组面板固定为 3×3。

### 搜索与快捷搜索

- “网站”页升级为“快捷搜索”，规则支持网页、应用/脚本和磁盘文件夹，并可用多个别名直接跳转目标。
- 搜索结果按名称完整匹配、开头匹配、包含匹配和路径匹配排序；可执行文件和脚本优先于普通文件、文件夹，并忽略常见扩展名参与名称比较。
- 快捷搜索结果在列表中单独标记，支持打开、编辑和删除，旧 `webs.json` 保留为本地备份。

## 1.0.0

整理日期：2026-10-26。以下记录相对于所继承 ltool 代码的 Hotaru 改动，涵盖首期开发的功能；不是新的发布版本号，也不将上游已有工具列为 Hotaru 新增功能。

### 设置页、快捷键与固定面板优化（开发中）

- 主面板右键菜单明确区分“添加程序或脚本…”、“添加磁盘文件夹…”和“新建面板文件夹”；分组面板禁止创建嵌套分组。
- 磁盘文件夹保存为 `targetType=folder` 固定项并打开真实目录；面板文件夹只保存 `groups` 配置，支持拖入、拖出和创建后重命名。
- 快捷键设置支持 `Alt+Space`、`Ctrl+K`、`Ctrl+Alt+K` 等标准组合及双击 Ctrl；第三方软件安装根目录补充 winget `--location` 说明、浏览和清空操作。
- 设置侧栏改用矢量图标，固定软件列表显示图标、类型、启用状态、路径和格位信息，主面板列数限制为 4–8，分组面板固定 3×3。
- 设置页固定软件增加统一拖放导入卡片；重命名使用带校验的统一对话框；“网站”页改为“快捷搜索”，规则独立保存并支持网页、应用和磁盘文件夹目标。
- 快捷键录入移除模式下拉框，改为原生消息捕获二级窗口；搜索结果按名称主体、可执行类型和路径相关度排序；固定项和快捷搜索拖放区域合并为单一提示卡片，新增按钮统一为灰色小按钮；取消新建面板文件夹不会写入配置。
- 固定项拖入卡片增加动态虚线和高亮反馈；F1/F2 仅在截图/录屏插件启用且声明动作时注册，插件禁用后不再弹出无主动作提示。

### 启动器和固定面板

- 启动器改为搜索条、固定网格和底栏组合，移除顶部分类、最小化及关闭控件；保留窗口拖动、缩放、热键和托盘入口。
- 全新首页默认黑色且固定项为空，不从应用索引或插件列表自动填充，也不占用一个“添加”图标格。
- 支持手动固定 exe、lnk、bat、cmd 和文件夹，配置参数、工作目录、自定义图标和启用状态。
- 固定项只显示图标与名称；右键提供运行、适用目标的管理员运行、定位、属性、重新定位、重命名和移除。
- 软件和分组的重命名只改变显示名称；移除只改变配置，不改动任何源文件或快捷方式。

### 自由格位、分页和分组

- 使用独立行列位置，支持留空、删除不补位和禁用项占位；减少列数时阻止隐藏已有项目。
- 默认每页4行8列，可选2–6行、4–8列；固定面板不滚动，支持按钮、滚轮和键盘翻页。
- 页面数量独立保存，支持新增空页、删除当前页，以及呼出时回首页或记住上次页码。
- 删除非空页可迁移到其他现有页面，或移除该页固定配置；迁移容量不足和写入失败时保护原布局。
- 拖动时提供虚线格、目标反馈和吸附动画，支持左右边缘停留跨页、末页新页预览及取消恢复，不挤动其他图标。
- 图标中心停留合并为分组，可继续加入图标、改名或解散；二级面板每页3×3，支持跨页和拖出到主面板。
- 仅一层分组，保留单项组，自动移除空组；分组与磁盘文件夹区分存储。

### 搜索和图标

- 非空查询使用独立结果列表，保留应用、文件和网站搜索；增加固定项及分组内软件搜索，不改变首页格位。
- 搜索结果右侧提供定位和固定按钮，悬停或键盘选中时显示；按钮操作不误触启动，支持快捷键和右键操作。
- 快速固定保留查询，使用首个空格，跨所有分组及禁用项判重；快捷方式保留自身启动信息。
- Windows 大图标异步提取，优先快捷方式自定义图标，其次真实目标，按资源、修改时间和请求尺寸缓存。
- 修复图标位图透明通道丢失形成的黑底，替换旧低清缓存键；DPI 变化时重新读取图标。
- 修复结果宽度计算导致的横向滚动，长结果文字省略，搜索列表仍允许纵向滚动。

### 外观与设置

- 内置黑、灰、白三种基础主题，默认黑色；增加用户 ZIP 皮肤的导入、切换、删除、校验与恢复。
- 本地自定义蓝色机械皮肤统一命名为“2233娘主题包”，保留原主题标识和作者信息，作为不随源码分发的独立 Release 附件。
- 皮肤支持透明外框、固定边拉伸、静态/GIF 装饰和固定源区域裁切，装饰鼠标穿透。
- 主题切换、同ID替换与删除时释放动画资源；非法资源、路径和不兼容布局拒绝安装，失败时保留当前主题。
- 启动器皮肤与设置/标准提示框配色隔离，修复提示文字过淡的问题。
- 统一设置入口，取消拖动和分组弹层后，在启动器所在屏幕还原、限尺寸、居中并激活设置窗口；增加现场诊断日志和原生命中检查。
- 底栏改为简短索引状态、页码与矢量齿轮，按统一区域对齐；内容区居中，不为单侧角色整体偏移网格。
- “呼出时显示常驻网格”控制整个固定面板，移除重复的“在首页显示固定软件”选项；固定配置和搜索能力保留。
- 关闭网格的空查询状态只保留搜索条皮肤与顶部角色，裁去多余底框和侧边块；结果展开后恢复完整结果外框及底部GIF，清空后收起并暂停底部动画。

### 数据、插件与构建

- 新增 Hotaru 布局配置，保存格位、持久页面、分组、启用状态及主题选择，支持完整布局导入和导出。
- 旧布局迁移前保留备份；读取文件句柄先关闭再原子替换，避免 Windows 文件占用导致保存失败。
- 损坏或无效配置保留副本后恢复默认；未知ID、重复格位、越界或容量不足等操作失败时保护原布局。
- 构建增加 `HOTARU_BUNDLE_PLUGINS`，默认关闭；保留原插件源码、已有插件文件及API v4。
- 插件自动更新默认关闭，首次进入 Hotaru 时迁移旧策略，之后只按用户显式选择执行。
- 复用 libarchive 读取皮肤 ZIP，并加强通用解压的绝对路径和目录穿越拒绝规则。
- vcpkg 显式选择 Qt 所需功能，减少未使用的依赖，沿用清单固定的 Qt 6.10.2。
- 增加 `--hotarutest`、`--hotarupreview`、`--theme-import` 和 `--theme-select`，更新原配置及插件更新测试的预期。

### Hotaru 1.0.0 首版界面与分发

- Hotaru 从 `1.0.0` 独立计版，界面、Windows 文件属性与安装器使用同一个版本源。
- 配置中的“萤主题”简化为“主题”；关于页改为品牌与版本卡片、本机信息卡片，路径可复制，支持基础明暗配色。
- 关于页仓库与发布入口指向 `EienSakura/hotaru-launcher`，不在该页展示上游介绍；上游归属保留在 README 和许可证。
- 插件商店常驻显示上游渠道与尚未测试适配说明；默认源固定在衍生前的上游 `v1.5.0`，不随 Hotaru 版本改变。
- 默认安装器和 CI 发布资产不含插件；额外插件构建、清单、SDK、校验与打包由显式开关控制，发布说明不会自动收集本机现有 DLL。
- README 增加维护者提供的固定面板和搜索界面截图，固定面板中的应用是手动添加示例。

### 产品命名与升级入口

- 显示名称统一为“萤 Hotaru”，主程序输出改为 `Hotaru.exe`；同步搜索、设置、托盘、关于页和主程序提示文字。
- 增加Windows文件属性中的产品名称、说明及版本信息，程序与托盘图标字母改为H；安装脚本使用Hotaru名称、独立安装标识和安装包名，CI同步执行文件及安装包路径。
- 保留内部CMake目标 `ltool`、核心 `ltoolcore.dll`、插件目录、API/IID/导出符号及已有数据标识，不重置用户配置；已有插件的标准旧标题提示框显示宿主品牌。
- 独立发布链验证前隐藏并禁用关于页在线升级，提供本项目仓库和发布页入口。
- 广告窗口检测按进程ID排除宿主自身，避免执行文件改名后误识别本程序；防火墙说明使用新名称并兼容识别旧规则。

### 自动发布接入

- 个人仓库接入 `hotaru/dev` 与 `main`，保留上游远端和历史；Hotaru 的版本标签与继承的上游标签区分处理。
- `.github/workflows/build.yml` 改用受支持的文件缓存，首版门禁以 `tools/upstream-base.txt` 为基线，不依赖上游标签出现在个人远端。
- `tools/make_release_notes.py` 支持显式主题附件，校验 ZIP、清单和重复文件，将独立主题纳入校验表；17项隔离自测覆盖默认无插件及主题附件。
- `src/LauncherTheme.h` 独立保存启动器专用主题类型，基础 `Theme.h` 不向上游插件暴露宿主布局，保持 API v4 与原有 ABI 门禁。
- 自动发布可以更新同标签草稿，保留维护者上传的独立主题，通过构建及回归后公开；不自动扫描、提交或上传本机素材。

### 验证与未覆盖范围

本轮 `1.0.0` 在项目内独立目录完成 Release 构建，关于页明暗配色与中文离屏预览检查通过。发布说明脚本13项检查、YAML与Bash语法、插件默认排除和文档链接/范围检查通过；商店检查不联网、不安装插件，未预装JSON插件时明确跳过六项真实DLL版本比较。

此前功能回归已覆盖格位、分页分组、源文件保护、主题校验、设置入口和GIF状态，并检查Windows三档缩放预览。本轮没有重复这些会占用桌面的原生交互测试，历史证据不代表重新验收。

物理鼠标手感、真实混合DPI切屏及真实UAC授权尚未完整验证，全部上游插件的功能适配仍未测试。云端CI、实际安装与在线升级尚未验收。原构建目录的核心DLL被当前实例占用，保留运行中的程序，使用独立目录验证，没有自动重启或覆盖用户实例。
