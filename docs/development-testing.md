# Hotaru 开发版实机测试

打开同名运行目录里的 `HotaruDev.exe`。如果只收到了 ZIP，先完整解压到单独的目录再打开。用 **Ctrl+Alt+H** 或托盘图标呼出。「萤 Hotaru 开发版」默认不开机自启，数据位于程序旁的 `data-dev`。

1. 连续打开两次开发版：第二次应呼出现有窗口。再打开正式版，两版应可同时使用各自的快捷键和设置。退出开发版后，正式版应继续运行。
2. 在开发版设置双击 Ctrl。快速轻点同一侧 Ctrl 两次，应在第二次松开时呼出；连续 `Ctrl+C`、`Ctrl+V`、单按 Ctrl 后复制、长按、左右混按都不应触发。若正式版也用了双击 Ctrl，这一项请先退出正式版。
3. 搜索 `calc`、`cmd.exe`、`记事本`，检查系统应用。添加同名关键词的快捷搜索后，规则应先选中，Enter 执行该规则。
4. 在桌面创建 `测试资料/创作工具箱/热键验证🎵.wav`，空文件也可以。索引就绪后搜「热键验证」，确认完整文件名和路径；再搜「创作工具箱」，确认目录能打开、定位和固定。
5. 可选：开发版自启关、开各登录一次，其余条件保持相同。记录是否抢焦点，以及同一款软件从登录到首个可用窗口的时间。测完关闭开发版自启，再移走测试目录。

仅包含局域网开发预览模块的测试包需要执行[局域网实测清单](lan-preview-testing.md)（测试包内为 `LAN-TESTING.md`）。
